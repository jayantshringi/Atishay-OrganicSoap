### Quick Overview of Identified Key Areas:
1. **Critical CSS & Design Token Fixes**: Resolving undefined Tailwind classes in `questionnaire/page.jsx` (`text-text-muted`, `bg-neutral`, `bg-accent-hover`).
2. **Font Loading Optimization**: Replacing `@import` in CSS with Next.js `next/font/google` for zero-CLS rendering.
3. **Icon Modernization**: Replacing informal emojis with crisp `lucide-react` vector icons.
4. **Mobile Quiz Experience**: Adding a responsive floating bottom sheet drawer so mobile users see the live 3D custom soap preview as they answer questions.
5. **Realistic 3D Soap Bar Aesthetics**: Upgrading `SoapPreview.jsx` with translucent glycerine effects, botanical specks (Haldi, Aloe, Sandalwood, Saffron), and debossed custom stamps.
6. **Admin Analytics with Recharts**: Utilizing the installed `recharts` library for revenue trends, order status breakdown, and customer skin profile distribution.
7. **Refined Checkout & Safety Trust**: Adding Razorpay trust seals, itemized breakdowns, and interactive 24h patch test steps.
